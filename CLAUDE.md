# Fakt — заметки для работы над проектом

- Назначение: ежедневный выпуск контента для личного бренда (сторис, карусель, рилс) на проверенных фактах. Подробности и структура — в README.md.
- Язык интерфейса и контента — русский. Голос контента — от первого лица владельца, без коучинговых штампов, каждая цифра с источником.
- Главный приоритет продукта — достоверность: не ослаблять правила проверки в `src/lib/brief.ts` и не добавлять в интерфейс демонстрационные или выдуманные данные. Выпуск в `data/editions/2026-09-18.json` — реальный ручной прогон по брифу, его можно использовать как эталон структуры.
- Схема выпуска — `src/lib/schema.ts` (Zod). Любое изменение формата выпуска начинается с неё, затем `brief.ts` (JSON_SHAPE) и компоненты.
- Клиентские компоненты импортируют из `schema.ts` только типы (`import type`), чтобы Zod не попадал в клиентский бандл и в статическое превью.
- Дизайн: токены в `src/app/globals.css` (тёмная тема по умолчанию, светлая через `prefers-color-scheme: light` или `data-theme="light"`), шрифты Unbounded / Manrope / JetBrains Mono, анимации — Framer Motion с учётом `prefers-reduced-motion`.
- Перед коммитом: `npm run typecheck && npm run lint && npm run build`.
